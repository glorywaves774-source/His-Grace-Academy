# Install Fr. Joseph Connolly SVD Memorial School as an app

The system can be installed on a phone, tablet or computer so it opens from its own icon, in its own window, like a normal app. It still runs from the school's online address, so everyone always sees the latest records.

## What you need

- The system must be hosted online with **HTTPS** (an address starting with `https://`). Hosting services such as Render give you this automatically. See `DEPLOY_ONLINE.md`.
- A modern browser: Chrome, Edge or Samsung Internet on Android and Windows; Safari on iPhone and iPad.
- Internet is needed to use the system. Without it, the app shows a short "You are offline" page.

## Android phones and tablets (Chrome)

1. Open the school's address in Chrome and wait for the sign-in page.
2. Tap **Install** on the bar at the bottom of the screen. (If the bar does not show, open the Chrome menu and tap **Install app** or **Add to Home screen**.)
3. The school icon appears on the home screen. Tap it to open.

## iPhone and iPad (Safari)

1. Open the school's address in **Safari** (not another browser).
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open the app from the new icon on the home screen.

## Windows or Mac computer (Chrome or Edge)

1. Open the school's address.
2. Click **Install** on the bar, or the install icon at the right end of the address bar.
3. The app opens in its own window and can be pinned to the taskbar or Start menu.

## Privacy on shared devices

- The app stores only the public look-and-feel files (colours, icons, scripts). **Student, fee, staff and result pages are never saved on the device.**
- Always use **Sign out** when finished, especially on a shared phone or computer.
- To remove the app, press and hold its icon (phone) or use the three-dot menu in the app window (computer) and choose **Uninstall / Remove**.

## If the install button does not appear

- Check that the address starts with `https://`.
- Open the page once, wait a few seconds, then reload.
- On iPhone, installing is only possible from Safari, using Share, then Add to Home Screen.
- If you dismissed the bar earlier, use the browser menu steps above.

## Hosting recommendation

Host the system online once, and let everyone install it from the link. This keeps one set of records, works from home and school, and is backed up in one place. If the school's internet is poor, the system can instead run on one office computer on the school network (see `DEPLOY_ONLINE.md`), but then it only works on that network and the computer must stay on.
